# Card Guard Agent（設計）

[English](README.md) | 日本語

> **設計段階：このリポジトリにコードはまだありません。** ここではアイデアを説明しています。作る前にエンジニアにコメントしてもらうためです。

**一言でいうと:** どのカードがどのサービスに登録されているかを記録しておくローカルエージェント。カードが漏洩したり、有効期限が切れたり、作り替わったときに、何をどの順番で変更すべきかがはっきりわかります。

## 問題

「このカードから請求しているサービスはどれですか？」に答えられる人はほとんどいません。カードは一度登録するとそのまま忘れられます: サブスクリプション、ショップ、アプリストア、ゲーム、公共料金など。カードが漏洩したり再発行されると、登録されていたことに気づくのは、決済が失敗し始めてから、あるいは不正利用の請求を見てから、ということになりがちです。あまり使わないカードは限度額が高いまま利用通知も設定されていないことが多く、それこそが不正利用の狙いやすさにつながります。

## できること

1. **カードマップ。** カードごとに、登録されているサービスのリスト。カードは自分で決めたラベルと下4桁だけで識別します。カード番号全体・有効期限・セキュリティコードは一切保存しません。
2. **限度額と通知チェック。** ほとんど使っていないのに限度額が高いカード、利用通知をオンにしていないカードに印を付け、カード発行会社自身の設定で何を変えるべきかを提案します。エージェント自身が設定を変更することはありません。
3. **漏洩・再発行プレイブック。** カードが漏洩したり作り替わったときに、そのカードに登録されているすべてのサービスをリスク順（定期課金とカード保存型のショップが最初）に並べ、各サービスでカードを更新・削除し、発行会社にも確認するためのチェックリストを出します。
4. **眠っているサブスクリプション。** まだ請求しているのに数か月使われていないサービスを指摘します。

## 原則

- **カード番号・有効期限・セキュリティコード・パスワードを保存しません。** 保存するのはラベルと下4桁だけ。
- **ローカルで動きます。** カードマップは自分のマシンだけに留まり、クラウドアカウントは不要。
- **助言するだけで、行動しない。** 銀行やカード発行会社にログインすることも、限度額を変えたり解約したりすることもありません。それはチェックリストを使いながらあなた自身が行います。
- **正直なステータス。** すべてのチェックで、確認できたことと確認していないことを明示します。

## 他のツールとの関係

- **[Account Keeper Agent](https://github.com/johnknash2025/account-keeper-agent)** は、どのサービスに登録したかをすでに記録しており、パスワードマネージャーの書き出しからサービス名とURLを取り込めます（パスワードは読みません）。Card Guard はそこにカードの情報を足します: 各サービスがどのカードから請求しているか。あえて分離して置き、アカウント情報と決済情報を一か所にまとめないようにしています。
- **[leakwatch-jp](https://github.com/johnknash2025/leakwatch-jp)** は、自分のメールアドレスやパスワードが既知の漏洩に出ているかを確認します。Card Guard はカードが漏洩したケースをカバーします。

## 未決の論点（コメント歓迎）

| 論点 | 重要な理由 |
|---|---|
| 明細を丸読みせずにカードマップを作る方法 | 明細には必要な情報よりはるかに多くが含まれます。エージェントは加盟店名・下4桁・金額だけを取るべきです。 |
| カード発行会社ごとに設定が大きく違う | 限度額と通知のアドバイスは汎用に保つか、発行会社ごとに書く必要があります。 |
| 仲介者（アプリストア、PayPal）を経由する定期課金 | 本来のサービスが仲介者の背後に隠れています。マップは両方を表示する必要があります。 |
